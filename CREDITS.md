# Credits and licences

## Art and audio in this project

All art and audio are original works created for this project. They are generated by code in this repository. **No third-party art, model, texture, font or sound files are included.**

| Asset | Source | Licence |
|---|---|---|
| Low-poly buildings, terrain, trees, townsfolk, roads, bridges | Generated in code: `client/Scripts/LowPolyMeshes.cs`, `TerrainRenderer.cs`, `RoadRenderer.cs` | Same as this project |
| Ambience (wind, birdsong), hammering, clicks, thuds, rubble, bells | Synthesized in code at startup: `client/Scripts/Audio/SoundSynth.cs` | Same as this project |

You can listen to every generated sound outside the game by exporting them to `.wav` files:

```bash
godot --path client -- --export-sounds /some/folder
```

## Rules for adding third-party assets later

Assets from the internet (models, textures, sounds, music, fonts) may only be added when **all** of these are true:

1. The licence has been read from the asset's **own source**: the licence file in the download, or the creator's page. A third-party listing doesn't count.
2. The licence allows commercial use and modification. CC0 / public domain is preferred. CC-BY is fine if the attribution it requires is added. Avoid "non-commercial" (NC), "no derivatives" (ND), "share-alike" (SA) for code-linked assets, and any "personal use only" terms.
3. The asset is listed in the table below with its creator, source URL, licence, and exactly what attribution is required. The licence file is kept next to the asset in the repository.
